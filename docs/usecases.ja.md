# ユースケース

本プロジェクトは Hegselmann & Krause (2002) の対称 BC 意見力学モデルを再現する．

## できること

1. **三相転移の観測．** 単一シミュレーションを実行し，信頼幅 ε が結果を支配する様子を見る: 小さな ε は多数のクラスタ (多元) を残し，中程度の ε は 2 陣営 (分極) を生み，大きな ε は合意に至る．[CLI → run](cli.ja.md) と [可視化](visualization.ja.md) を参照．

   ```bash
   cargo run --release -- run --n 625 --eps 0.05 --start uniform --seed 42   # 多元
   cargo run --release -- run --n 625 --eps 0.15 --start uniform --seed 42   # 分極
   cargo run --release -- run --n 625 --eps 0.25 --start uniform --seed 42   # 合意
   uv run hegselmann-bc-tools visualize
   ```

2. **ε 走査で相図を作る．** `sweep` を実行して `[0.01, 0.40]` で ε を走査し，各 ε での生存意見数の平均を集計する．論文 §4 は `ε > 0.4` ならば `n` や初期分布に依らず常に合意することを報告しており，sweep 図がそれを具体化する．

   ```bash
   cargo run --release -- sweep --eps-min 0.01 --eps-max 0.40 --eps-step 0.01 \
       --n 625 --start uniform --runs 50 --seed 42
   uv run hegselmann-bc-tools visualize-sweep
   ```

3. **初期分布の比較．** `--start uniform` ↔ `--start regular` を切り替えて，決定論的な等間隔プロファイル (`x_i = i/(n-1)`) が整数の分裂数 (論文 Fig. 4–8) を出すのに対し，一様乱数プロファイルがノイジーだが一貫した統計 (Fig. 3 / 12) を出すことを観察する．

   ```bash
   cargo run --release -- run --n 100 --eps 0.05 --start regular --seed 1   # Fig. 7 設定 (≈ 8 splits)
   uv run hegselmann-bc-tools visualize
   ```
