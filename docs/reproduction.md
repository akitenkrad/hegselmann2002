# Reproduction

This page tracks the status of paper-figure reproduction.

## Status: Phase 3 not yet started

A one-shot `reproduce_paper.py` (batch-running the Rust binary and rendering paper Figures 2 / 3 / 7 / 8 / 12 etc.) is planned as **Phase 3** of the implementation roadmap and is **not yet started**. Phase 3 also adds the asymmetric BC mechanism (`AsymmetricHegselmannKrauseMechanism`, paper §4 Fig. 10–13) which is required to reproduce Fig. 10 / 11 / 13.

In the current Phase 1 + Phase 2 scope you can already cover the qualitative content of:

| Paper figure | How to reproduce with current Phase 1/2 |
|---|---|
| Fig. 2 (n = 38, ε = 0.1) | `cargo run --release -- run --n 38 --eps 0.1 --start regular --seed 1` + `uv run hegselmann-bc-tools visualize` |
| Fig. 3 (n = 625, ε sweep) | `cargo run --release -- sweep --eps-min 0.01 --eps-max 0.40 --eps-step 0.01 --n 625 --runs 50 --seed 42` + `visualize-sweep` |
| Fig. 7 (n = 100, ε = 0.05, regular, "8 splits") | `cargo run --release -- run --n 100 --eps 0.05 --start regular --seed 1` + `visualize` |
| Fig. 8 (n = 100, ε = 0.25, regular) | `cargo run --release -- run --n 100 --eps 0.25 --start regular --seed 1` + `visualize` |
| Fig. 12a / 12c (symmetric ε sweep) | same `sweep` invocation as Fig. 3; the top panel of `visualize_sweep.png` is Fig. 12a, the bottom panel is Fig. 12c |
| Fig. 10 / 11 / 13 (asymmetric) | **Phase 3** — requires `--eps-l` / `--eps-r` and the asymmetric mechanism |

## Quantitative reproduction targets

These are the numerical benchmarks defined in the design document (paper §4):

| Setting | Metric | Paper value | Tolerance |
|---|---|---|---|
| 625 opinions, uniform, ε = 0.01 | surviving opinions | 38 | ±3 |
| 625 opinions, uniform, ε = 0.15 | phase | polarization (2 camps) | qualitative |
| 625 opinions, uniform, ε = 0.25 | phase | consensus | qualitative |
| any n, ε > 0.4 | phase | always consensus | qualitative |
| 100 opinions, regular, ε = 0.05 | splits | 8 | ±1 |
| 100 opinions, regular, ε = 0.25 | phase | consensus (no split) | qualitative |
| 625 opinions, symmetric ε | final mean | ≈ 0.5 | ±0.02 |

The `reproduce_paper.py` Phase 3 deliverable will batch-run each row and emit a single comparison report; for now you can spot-check each row manually with `run` / `sweep` + `visualize` / `visualize-sweep`.
