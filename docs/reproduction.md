# Reproduction

This page tracks the status of paper-figure reproduction.

## Status: Phase 3 complete — `reproduce` subcommand available

The one-shot Python driver `reproduce_paper.py` is shipped as the `reproduce` subcommand of `hegselmann-bc-tools`. It batch-runs the Rust binary (`cargo run --release -- run / sweep ...`) once per Figure spec and writes a single bundle under `results/reproduce_<timestamp>/figures/`. Phase 3 also adds the asymmetric BC mechanism (`--eps-l` / `--eps-r`; paper §4 Fig. 10–13), which is required for Fig. 11.

```bash
uv run hegselmann-bc-tools reproduce            # full reproduction (paper values)
uv run hegselmann-bc-tools reproduce --quick    # lightweight smoke run (n=125, runs=5)
uv run hegselmann-bc-tools reproduce --specs fig02,fig03
```

See [`visualization.md`](visualization.md#reproduce--batch-paper-figure-reproduction) for the complete CLI reference and output layout.
