# 論文再現

論文 Figure の一括再現状況を記述する．

## 状態: Phase 3 完了 — `reproduce` サブコマンドで一括再現可能

Python ドライバ `reproduce_paper.py` は `hegselmann-bc-tools` の `reproduce` サブコマンドとして提供される．Rust バイナリ (`cargo run --release -- run / sweep ...`) を Figure spec ごとに 1 回ずつ呼び出し，`results/reproduce_<timestamp>/figures/` 配下の単一ディレクトリに PNG を集約する．Phase 3 では非対称 BC mechanism (`--eps-l` / `--eps-r`，論文 §4 Fig. 10–13) も併せて追加され，Fig. 11 の再現に必要となる．

```bash
uv run hegselmann-bc-tools reproduce            # フル再現 (論文値)
uv run hegselmann-bc-tools reproduce --quick    # 軽量モード (n=125, runs=5, 動作確認用)
uv run hegselmann-bc-tools reproduce --specs fig02,fig03
```

CLI リファレンスと出力レイアウトは [`visualization.ja.md`](visualization.ja.md#reproduce--論文-figure-一括再現) を参照．

| 論文 Figure | Spec ID | サブコマンド | パラメータ | 期待される結果 |
|---|---|---|---|---|
